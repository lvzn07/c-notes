# c-notes

C 语言学习笔记与示例代码。

## 文件说明

### 三角形面积计算.c

已知三角形三条边长，使用**海伦公式**计算面积。

海伦公式：设半周长 `s = (a + b + c) / 2`，则

```
area = √( s × (s - a) × (s - b) × (s - c) )
```

程序读取三个浮点数作为边长，输出计算结果。

> 注意：源码中调用了 `math.h` 的 `sqrt()`，编译时必须链接数学库（`-lm`），否则会报未定义引用。
> 另外源码未显式 `#include <stdio.h>`，部分编译器会给出隐式声明警告，建议补上。

### Changes.c

简单的找零计算。输入消费金额（整数元），程序以 100 元为基准算出应找零的数额。

## 编译与运行

需要先安装 GCC（Windows 下可用 MinGW-w64 或 MSYS2）。

```bash
# 三角形面积计算（-lm 用于链接数学库）
gcc 三角形面积计算.c -o triangle -lm
./triangle

# 找零计算
gcc Changes.c -o changes
./changes
```

运行示例：

```
$ ./triangle
输入边长3 4 5
area=6.000000

$ ./changes
请输入金额(元) : 37
找您63元
```
