# C Notes

C 语言学习笔记与示例代码仓库。

## 目录

| 文件 | 说明 |
|------|------|
| `三角形面积计算.c` | 三角形面积计算 —— 使用海伦公式（已知三边求面积） |
| `Changes.c` | 找零计算 —— 输入金额，计算应找零（基于 100 元） |

## 使用说明

1. 确保已安装 GCC 编译器
2. 编译运行示例：

```bash
# 三角形面积计算
gcc 三角形面积计算.c -o triangle -lm
./triangle

# 找零计算
gcc Changes.c -o changes
./changes
```

## 备注

- 三角形面积计算使用了 `math.h` 中的 `sqrt` 函数，编译时需加 `-lm` 链接数学库
- 找零计算默认以 100 元为基准金额
